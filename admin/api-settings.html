入力者の追加・変更、通知先や署名の設定はスプレッドシートの「入力者」「設定」シートで行います （スプレッドシートを開く）。 変更後は「選択肢を同期」を押してください（毎朝6時にも自動で同期されます）。

GAS 側のセットアップ手順（初回のみ・PC推奨）
  1. ファイルを追加
    Apps Script プロジェクトに、リポジトリの gas/ フォルダにある FormIntegration.gs / LabelPdf.gs / LabelTemplate.gs / QRCode.gs / Tests.gs を同じ名前で追加し、 Code.gs を gas/Code.gs の内容に更新します（doGet の委譲と署名の設定シート化）
  2. サービスの確認
    左メニュー「サービス」に Drive API（v2）が追加されていることを確認（起案書作成を使っていれば追加済み）
  3. setupFormIntegration を実行
    関数を選んで実行し、権限を承認します。設定・入力者・箱台帳シート、入荷/出荷フォーム、トリガー、ラベルテンプレートが作られます
  4. シートを記入
    「入力者」シートに 名前・メール・有効(TRUE)、「設定」シートに adminEmail と署名（orgName, senderName など）を記入し、 syncFormChoices を実行します
  5. 試し刷り
    test_sampleLabelPdf を実行して PDF をエーワン 31266 に印刷し、ズレがあれば「設定」シートの offsetX_mm / offsetY_mm で調整します
  6. 新しいバージョンでデプロイ
    「デプロイを管理」→ 編集 → バージョン「新バージョン」→ デプロイ（URL は変わりません）。 この画面の「状態を更新」でフォームが表示されれば完了です

📋 セットアップ手順

初回セットアップはPCでの作業を推奨します。
  1. Google Apps Scriptを開く
    script.google.com にアクセスし、「新しいプロジェクト」を作成
  2. スクリプトを貼り付け
    提供された「Code.gs」の内容をエディタに貼り付けて保存
  3. 初期化を実行
    「initializeSpreadsheet」関数を選択して実行（初回のみ権限承認が必要）
  4. Webアプリとしてデプロイ
    「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選択
    アクセスできるユーザー: 「全員」に設定してデプロイ
  5. URLをコピー
    表示されたWebアプリURLをコピーして上の入力欄に貼り付け
  6. 接続テスト
    「接続テスト」ボタンをクリックして正常に接続できることを確認
  7. 他のスマホへ共有（任意）
    「QR生成」タブでQRコードを生成し、他のスマホで「QRスキャン」から読み取り
