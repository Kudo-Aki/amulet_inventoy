# お守り在庫管理アプリ 簡易マニュアル

## はじめに

このアプリは、お守りの箱に貼られたQRコードをスマホで読み取って、在庫を数えるためのものです。

**ポイント**
- 同じ箱を2回読み取っても、数は増えません（安心して使えます）
- 読み取った結果はCSVファイルで出力できます

---

## 準備するもの

1. **スマホ**（iPhone または Android）
2. **QRコードが貼られたお守りの箱**

---

## 基本的な使い方

### ステップ1: アプリを開く

1. スマホのブラウザ（Safari や Chrome）でアプリを開きます
2. 「お守り在庫管理」の画面が表示されます

### ステップ2: モードを選ぶ

| モード | いつ使う？ |
|--------|-----------|
| 📦 **納品モード** | 新しいお守りが届いたとき |
| 📋 **棚卸モード** | 今ある在庫を数えるとき |

1. 使いたいモードのボタンを押します
2. 確認画面が出るので「開始する」を押します

### ステップ3: QRコードを読み取る

1. カメラが起動します
2. お守りの箱のQRコードをカメラに映します
3. 読み取りに成功すると、商品名が表示されます

**読み取りのコツ**
- QRコードを画面の真ん中に映す
- 明るい場所で読み取る
- カメラを近づけすぎない（20〜30cm程度）

### ステップ4: 読み取りを終了する

1. すべての箱を読み取ったら「読み取り終了」ボタンを押します
2. 集計結果が表示されます

### ステップ5: CSVを出力する

1. 「CSV出力」ボタンを押します
2. ファイルがダウンロードされます
3. このファイルをExcelで開くと、Airレジへの入力に使えます

---

## 同じ箱を2回読み取ってしまったら？

**大丈夫です！**

同じQRコードを2回読み取ると、以下のような警告が表示されます：

```
⚠️ 重複検知

この箱はすでに登録されています。
数量は増えません。
```

「OK」を押して、次の箱を読み取ってください。

## よくある質問

### Q: カメラが起動しない

**A:** ブラウザがカメラを使う許可を求めてきたら「許可」を押してください。

### Q: QRコードが読み取れない

**A:** 以下を試してください：
- 明るい場所に移動する
- QRコードをまっすぐカメラに向ける
- 少し離れて読み取る

### Q: 途中でアプリを閉じてしまった

**A:** 残念ながら、読み取りデータは消えてしまいます。最初からやり直してください。

### Q: 読み取った数が合わない

**A:** 以下を確認してください：
- 読み取り忘れた箱がないか
- 同じ商品の別の箱を読み取ったか（同じ箱を2回読んでも増えません）

## QRコードの見方

QRコードには以下の情報が入っています：

```
HEALTH-25-0001
  │     │   │
  │     │   └── 箱の番号（0001〜9999）
  │     └────── 年度（25 = 2025年）
  └──────────── 商品コード（英大文字のみ）
```

> 商品コードは**英大文字だけ**です。数字や小文字を含むコードは読み取れません。

**商品コード一覧**

| コード | 商品名 |
|--------|--------|
| HEALTH | 健康守り |
| MONEY | 金運守り |
| LOVE | 縁結び守り |
| TRAFFIC | 交通安全守り |
| STUDY | 学業成就守り |
| FAMILY | 家内安全守り |
| BUSINESS | 商売繁盛守り |
| CHILD | 子授け守り |
| RECOVERY | 病気平癒守り |
| LUCK | 開運守り |

## スマホのフォームから登録する方法（スキャンしない場合）

Googleフォーム連携を設定していれば、QRコードを読まずにスマホのフォームから登録できます。
フォームのURLとQRコードは、担当者から共有されます（倉庫に貼ってあることもあります）。

| フォーム | 使うとき | 入れるもの |
|---|---|---|
| **お守り入荷登録** | 荷物が届いたとき | 自分の名前・商品・箱数（最大10商品） |
| **お守り出荷登録** | 授与所へ持ち出すとき | 自分の名前・商品・箱数（端数）・出荷先 |
| **お守り棚卸登録** | 在庫を数えたとき | 自分の名前・商品・**数えた実際の個数**（最大10商品） |
| **お守り商品登録** | 一覧に無い授与品が出てきたとき | 商品名・商品コード・入数（今ある個数） |

入荷フォームを送ると、1〜2分で箱に貼るラベルのPDFがメールで届きます。印刷して各箱に貼ってください。

**棚卸フォームで気をつけること**

- **空欄と 0 は意味が違います。** 空欄＝「数えていない」（在庫はそのまま）、`0`＝「在庫ゼロ」（0個として記録）
- 商品だけ、数量だけを入れるとエラーになります。数え終わった商品だけ、商品と個数の両方を入れてください
- 一度に数え切れないときは、何回かに分けて送って構いません
- 送る前の在庫は自動で控えられます。間違えても担当者が戻せます

**商品登録フォームで気をつけること**

- 商品コードは**英大文字のみ 1〜12文字**（例: `KOTSU`）。数字・小文字・記号は使えません
- 規則から外れているとエラーになります。エラーのメールが担当者に届きます
- 今ある個数が分かれば「初期在庫」に入れてください。登録と在庫の記録が1回で済みます

```
1. アプリを開く
      ↓
2. モードを選ぶ（納品 or 棚卸）
      ↓
```
